Get a key once

  1. Open Google Cloud → Books API, choose your project, and enable the API.
  2. Open Credentials, create an API key, and restrict it to the Books API.
  3. Paste it in the field above, save, and test the connection. This is a server API key; website referrer restrictions do not apply to server requests.

The key is kept in book_api.local.toml on this server, excluded from version control and never shown again in this form. It is not encrypted on disk; protect project-folder access. A server environment variable named GOOGLE_BOOKS_API_KEY takes precedence. Only superusers can manage credentials.

No provider guarantees every edition's cover. Missing or broken images retain the library's decorative cover. Images remain on Google's servers; your database stores their URLs.
